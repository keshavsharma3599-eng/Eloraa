ELORA FINE DINING — SCHOOL PROJECT WEBSITE

FILES
- index.html: webpage structure
- style.css: visual design and responsive layout
- script.js: mobile navigation and contact form interaction
- images/: locally included food photographs used by the webpage

HOW TO OPEN
1. Extract the ZIP folder.
2. Open the elora-restaurant folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Keep the images folder beside index.html and do not rename it.
